# 《达芬奇密码》规则调研

本插件实现的是桌游《达芬奇密码》（*Da Vinci Code*，日文版又称 *Coda*）。
以下规则整理自 UltraBoardGames 官方规则页与若干开源实现，并标注了本插件的取舍。

## 配件

| 牌 | 数量 |
| --- | --- |
| 黑色 `0-11` | 12 |
| 白色 `0-11` | 12 |
| 黑色百搭（Joker / Scramble Tile） | 1 |
| 白色百搭 | 1 |
| **合计** | **26** |

> 官方基础版会移除两张百搭，只玩 24 张数字牌；加入百搭属于进阶玩法。
> 本插件默认采用含百搭的 26 张（更常见、更有博弈）。

## 开局

1. 洗混全部牌，放在桌子中央作为牌堆。
2. 每人抽 4 张（4 人局每人 3 张）。
3. 按数字从小到大、从左到右排成一行，数字相同则 **黑色在白色左边**；
   百搭可以放在任意位置。
4. 牌背朝向其他玩家，只有本人能看自己的牌。

## 回合流程

轮到你时：

1. **抽牌**：从牌堆抽 1 张，称为「线索牌」，放在自己面前，只有你能看。
   抽到百搭时，先决定它插在自己牌列的哪个位置。
2. **猜牌**（必做）：指定任意一名对手的任意一张暗牌，报出你认为的数字
   （`0-11`，或表示「百搭」的 `-`）。
   - **猜中**：对手把这张牌翻开（此后一直公开）。你可以：
     - **继续猜**：重复第 2 步，且不能再抽牌；或
     - **收手**：结束回合，把线索牌 **暗扣** 进自己牌列的正确位置。
   - **猜错**：回合立即结束，把线索牌 **亮出** 并插进自己牌列的正确位置。

## 结束与胜负

- 一名玩家所有牌都被翻开时立即出局，不再行动。
- 只剩最后一名还有暗牌的玩家时，该玩家获胜。
- 牌堆抽空后仍继续轮流猜牌；此时猜错不再需要亮牌（因为无牌可亮）。

## 本插件的取舍

| 规则点 | 官方 / 常见做法 | 本插件做法 | 原因 |
| --- | --- | --- | --- |
| 抽牌 | 玩家主动抽 | 回合开始自动抽并发私密按钮 | 减少一步操作，聊天窗口更顺畅 |
| 百搭位置 | 玩家自行决定 | 随机位置 | 避免额外交互；位置信息只在本人手牌按钮里可见 |
| 抽到百搭 | 玩家选择插入位置 | 抽到即随机落位 | 省去一次公开操作；百搭位置本来就不影响数字牌排序 |
| 猜牌是否必做 | 必须猜一次 | 必须猜一次 | 与官方规则一致 |
| 线索牌归属 | 抽牌后放在一旁 | 存在 `pending`，回合结束才插入牌列 | 与官方时序一致 |
